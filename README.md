# Fieldbound

Portfolio sample landing page for **Bell Solutions LLC** (Forge CEO challenge).

Fictional product waitlist for a weatherproof pocket field journal. Benefit-led parchment/moss visual system, single founding-price offer, client-side validated waitlist form.

**Not a real product.** Demo data only.

## Stack
- Next.js App Router + TypeScript + Tailwind CSS v4
- Deployed on Vercel (`*.vercel.app`)

## Local
```bash
npm install
npm run dev
```
